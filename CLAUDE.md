# Проєкт
Чистий HTML + CSS + JS, без фреймворків і збирачів.

## Правила
- Використовуй ванільний JavaScript (ES2022+); підключай скрипти через `<script type="module">`.
- Зберігай CSS у `css/style.css`; оголошуй CSS-змінні в `:root`.
- Пиши коментарі українською, назви змінних — англійською.
- Після змін коротко пояснюй, що змінилося.

## Межі змін
- Не переписуй код, який не потрібно змінювати для виконання запиту; внось лише цільові, мінімальні зміни.
- Змінюй тільки функцію або можливість, якої стосується запит. Не змінюй і не видаляй не пов'язані з ним функції та можливості й зберігай решту наявної поведінки програми.
- Виконуй вимоги запиту точно. Якщо для виправлення необхідна суміжна зміна, обмеж її тим, що безпосередньо потрібно для результату.

## Відповіді
- Не надсилай повідомлень про хід роботи; після виконання надай лише короткий підсумок результату.

## Журнал версій
- Під час змін функціоналу програми оновлюй журнал версій у `README.md`: додавай дату й час, номер версії та зрозумілий опис змін.
- Додавай новий запис на початок журналу, зберігаючи записи в порядку від найновішого до найстарішого. Сортуй ці записи по порядку нумерації версій.
